# أدوات الذكاء الاصطناعي للشغل من الصفر

أكاديمية تفاعلية بالعربي (عامية مصرية) لاستخدام أدوات الـ AI في الشغل والدراسة بشكل آمن، جزء من منصة أكاديميات Infinity University Activity.

**الموقع المباشر:** https://capwv.github.io/ai-tools-from-zero/

## المحتوى

- **14 درس**
- **42 سؤال تفاعلي** بتصحيح فوري وشرح
- **28 تمرين** بحل نموذجي
- **معمل** جوه المتصفح: بناء برومبت، مقارنة برومبتات، "ينفع ألصقه"، والتحقق

المعمل بيشتغل من غير أي اتصال بنموذج AI.

## الدروس

1. إيه هو الـ Generative AI
2. أنواع الأدوات
3. أساسيات البرومبت
4. تحسين البرومبت
5. الهلوسة والتحقق
6. الخصوصية في الشغل
7. الكتابة مع الـ AI
8. البحث والتعلم
9. البيانات والجداول
10. العروض والتصميم
11. الإنتاجية
12. الأتمتة والـ Agents
13. الشغل والمستقبل
14. المشروع الختامي
